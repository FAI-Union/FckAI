# Campaigns / 活动记录

Records of petitions, open letters, and public campaigns, including the decisions that authorized them (see [Governance](../GOVERNANCE.md)).

联署、公开信与公共活动的记录，包括授权这些行动的决策（见[治理规则](../GOVERNANCE.md)）。

## Rules / 规则

- No harassment, no threats, no sabotage — see the [red lines](../README.md#our-red-lines) and [Code of Conduct](../CODE_OF_CONDUCT.md).
- Factual claims must cite a source in `RESEARCH/`.
- Every campaign decision must be traceable to a Discussion or Issue record.

不骚扰、不威胁、不破坏——见[红线](../README.md#our-red-lines)与[行为准则](../CODE_OF_CONDUCT.md)。事实性主张必须引用 `RESEARCH/` 中的来源。每项活动决定都必须可追溯到 Discussion 或 Issue 记录。
