# Policy Proposals / 政策建议书

Draft policy proposals related to the four focus areas: training-data consent, job displacement and retraining, energy disclosure, and algorithmic accountability.

围绕四个关注领域（训练数据知情同意、就业冲击与再培训、能耗披露、算法问责）的政策建议书草案。

## Format / 格式

Each proposal should state: the problem, the proposed measure, the evidence base (link to `RESEARCH/`), and expected trade-offs.

每份建议书应说明：问题、建议措施、证据基础（链接到 `RESEARCH/`）、预期利弊。
