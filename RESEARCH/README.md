# Research / 证据库

Evidence library with sources. Every factual claim in this project must trace back to an original source here.

带来源的证据库。本项目中每一条事实性主张都必须可追溯到此处的原始来源。

## Contributing / 贡献

When adding evidence, include:

- The claim being supported
- Original source (link, document, dataset) and publication date
- A short quote or excerpt
- Any caveats about reliability

When submitting a claim without a source, it will be tagged `needs-source` and will not be used as a basis for decisions (see [Governance](../GOVERNANCE.md)).

添加证据时请包含：被支持的主张、原始来源（链接/文档/数据集）及发布日期、简短引述、可靠性说明。无来源的主张会被标记为 `needs-source`，不作为决策依据（见[治理规则](../GOVERNANCE.md)）。
