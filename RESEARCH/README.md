# Research / AI ethics evidence index

Evidence library with sources. Every factual claim in this project must trace back to an original source here. This index is the canonical entry point for the **AI accountability evidence archive**: sourced evidence on training-data consent, AI energy cost, job displacement and deepfake accountability.

带来源的证据库。本项目中每一条事实性主张都必须可追溯到此处的原始来源。本索引是 **AI 问责证据库**的权威入口。

Last updated: 2026-11-26 · 21 evidence cards · 20 external sources · all cards carry ID, claim, source, date, excerpt and caveats.

## Contributing / 贡献

When adding evidence, include:

- A unique evidence ID (`EV-YYYY-NNN`) in frontmatter and in the H1
- The claim being supported, in English and Chinese
- Original source (link, document, dataset) and publication date
- A short verbatim quote or excerpt
- Caveats about reliability, scope and interpretation
- `tags` in frontmatter so the card can be grouped in this index

When submitting a claim without a source, it will be tagged `needs-source` and will not be used as a basis for decisions (see [Governance](../GOVERNANCE.md)).

## How to use / 使用方式

- Policy proposals must cite at least one `EV-YYYY-NNN` ID — see [POLICY/](POLICY/).
- Campaigns must link to the discussion or issue that authorised them — see [CAMPAIGNS/](CAMPAIGNS/).
- Translations of a card keep the same ID and add a locale suffix, e.g. `EV-2026-001.zh-CN.md`.
