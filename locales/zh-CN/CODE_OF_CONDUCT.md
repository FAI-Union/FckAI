# 行为准则

## 我们的承诺

我们承诺让每个人都能不受骚扰地参与本社区，无论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性取向与身份。

我们承诺以有助于建设开放、欢迎、多元、包容、健康社区的方式行动与互动。

## 我们的标准

有助于营造积极环境的行为示例：

- 对他人表现出同理心与善意
- 尊重不同的观点、看法与经历
- 给予并得体地接受建设性反馈
- 承担责任，向受我们错误影响的人道歉，并从中学习
- 以整体社区的最佳利益为重

不可接受的行为示例：

- 使用性化的语言或图像，以及任何形式的性关注或性挑逗
- 抬杠、侮辱性或贬低性评论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可发布他人的私人信息，如住址或电子邮箱
- 其他在专业场合可合理视为不当的行为

## 执行责任

社区领导者负责澄清并执行我们的可接受行为标准，并对任何其认为不当、威胁、冒犯或有害的行为采取适当且公正的纠正措施。

社区领导者有权删除、编辑或拒绝不符合本行为准则的评论、提交、代码、维基编辑、议题及其他贡献，并会在适当时候说明审核决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表本社区的情形。

## 执行

辱骂、骚扰或其他不可接受的行为可通过私密议题或讨论向负责执行的社区领导者举报。所有投诉都将被及时、公正地审查与调查。

所有社区领导者有义务尊重事件举报者的隐私与安全。

## 执行指南

社区领导者将遵循以下社区影响指南，对其认定违反本行为准则的行为决定后果：

### 1. 纠正

**社区影响**：使用不当语言或社区认为不专业、不受欢迎的其他行为。

**后果**：社区领导者发出私下书面警告，说明违规性质并解释为何行为不当。可能要求公开道歉。

### 2. 警告

**社区影响**：单次事件或一系列行动构成的违规。

**后果**：警告，并对后续行为设定后果。在指定期限内不得与相关人员互动，包括与本行为准则执行者的非自愿互动。违反这些条款可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定期限内禁止与社区进行任何形式的互动或公开交流。不得与相关人员有任何公开或私下互动。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：呈现违反社区模式的行为，包括持续的不当行为、对个人的骚扰，或对某类人群的攻击或贬低。

**后果**：永久禁止在社区内进行任何公开互动。
